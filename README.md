# Echoes of Orbital-9

A text-based choose-your-own-adventure game in Python. Explore the damaged
Orbital-9 space station, restore its power, find the escape-pod keycard, and
decide whether to send a distress signal before escaping.

## Scoring

You earn points for completing important objectives:

- Restore the reactor: 25 points
- Find the escape-pod keycard: 25 points
- Send a distress signal: 25 points
- Escape with the rescue ship: 25-point bonus

The best possible score is 100. Your final score is shown with your ending.

## Run the game

Requires Python 3.9 or newer.

```text
python game.py
```

At each prompt, enter the letter shown for the action you want to take.

## Run the tests

```text
python -m unittest -v
```
